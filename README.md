# 🏮 Echoes of the Lantern

A peaceful haven management RPG where reincarnated souls find their way home.

## 🎮 About

Echoes of the Lantern is a browser-based idle game where you manage a haven for wandering souls. Summon heroes, watch them go on adventures, and build your peaceful sanctuary.

## ✨ Features

- **Simple & Stable**: Clean code with no complex dependencies
- **Idle Gameplay**: Heroes automatically go on adventures
- **Hero Management**: Summon and level up unique heroes
- **Auto-Save**: Game saves automatically every 30 seconds
- **Responsive Design**: Works on desktop and mobile browsers

## 🚀 How to Play

1. Open `index.html` in a web browser
2. Click "Summon Hero" to recruit your first hero (costs 50 gold)
3. Watch your heroes go on adventures automatically
4. Earn gold and experience as they complete activities
5. Level up your heroes and summon more companions

## 🎨 Design

- **Aesthetic**: Warm pastel colors with a cozy, welcoming feel
- **Theme**: Japanese-inspired fantasy with reincarnation motifs
- **UI**: Clean, readable interface with smooth animations

## 💾 Save System

- Auto-saves every 30 seconds to browser localStorage
- Manual save/load buttons available
- Save data includes heroes, gold, and progress

## 🛠️ Technical Details

- Pure JavaScript (ES6 modules)
- No external dependencies
- Simple JSON-based data storage
- Responsive CSS Grid layout
